## Upstream delta and native adaptations

The upstream kernel delta touches38 paths (including removal of
`hook/syscall_table_mirror.c` and addition of `hook/syscall_table_mirror_arm64.c`).
It includes unified ADB-root/preinit exec helpers, sucompat exec rework,
SELinux-hide changes, expanded sulog events, compatibility helpers and version
updates. Driver metadata records every upstream blob and every local override.

1. Retain KSU default-n, private SELinux generated-header dependencies,
   UTS_MACHINE Kbuild definition, SUSFS2.4, NoMount and FinaSU integration.
2. A three-way merge conflicts in sucompat: upstream now attempts nested native
   exec of an opened ksud FD and converts compat argv/envp. That is not compatible
   as-is with the SUSFS hook contract, which executes the original native/compat
   syscall and installs the SU descriptor after a successful return. For
   `CONFIG_KSU_SUSFS && CONFIG_KSU_TAMPER_SYSCALL_TABLE`, retain the reviewed
   original-syscall front end and its UID/allowlist/zygote/post-exec protections.
   Adapt that front end to unified ADB/preinit APIs and runtime sulog. All8
   native/compat wrapper branches retain the successful-return helper. Other
   configurations retain upstream's new front end; they are not build/runtime
   validated by this update. This is an adapted update, not a claim that every
   new upstream exec implementation runs in the selected profile.
3. Keep both setprocattr and the newly introduced setxattr mutation hooks as
   no-ops with SUSFS: native typed SELinux filters remain authoritative. The
   initially clean textual merge wrongly spanned the new function with an old
   preprocessor guard; corrected separate guards are compiled by host tests.
4. Do not shadow existing native audit_context(), __poll_t or
   strncpy_from_user_nofault() with legacy fallbacks. These are present in this
   tree, including BPF-era nofault support. New upstream helpers are otherwise
   retained. This does not alter global BPF, audit or uaccess implementation.
5. Upstream removed CONFIG_KSU_FEATURE_SULOG: sulog is now always compiled,
   runtime-disabled initially. Remove only the obsolete miatoll selector;
   existing config flags/hooks and TCP bbr3/fq defaults remain unchanged.
   The retained SUSFS exec front end uses the new runtime-gated event interface
   with filename-only/empty-argv semantics, replacing its old payload-free event.
6. Update honest display strings to v3.3.1+50. FinaSU package/certificate trust,
   verified-package UID binding, cached manager revalidation and one-active-
   manager policy remain; no manager binary replacement or root bypass.

The additive patch records all predecessor/successor bytes, including source
addition/removal and metadata. Closed inverse/forward replay reconstructs the
pre-update sources on copies, then runs immutable historical KSU/FinaSU/SUSFS
receipts and negative suites. Existing legacy test entry points first validate
the current +50 layer, explicitly announce predecessor replay, and run their
original checks on detached copies. Their old32717/104-file seals are NOT
rewritten to bless new code. New-code runtime models are separate, not inferred
from passing historical tests.

Commands:

```sh
python3 tools/testing/selftests/kernelsu/test_update50.py --self-test-negatives --historical
python3 tools/testing/selftests/nomount/test_integration.py
```

The helper uses temporary hardlinked read-only fixtures to avoid duplicating
the kernel, detaches all changed files before reverse replay, and never writes
predecessor bytes over the working source. Temporary fixtures are removed.
No production compiler flags are weakened to make host models pass.

## Limits

Kconfig are not production proof. Preserve a known-good boot image and validate
both native and32-bit su, manager authorization, failed exec, SUSFS/NoMount,
sulog toggle, ADB root toggle and SELinux enforcing behavior before daily use.
