## Upstream delta

- Version32717; kernel include and compatibility-shim adjustments.
- Read-only pointer patching tries no-fault writing/readback before the existing
  writable-vmap fallback; callers use `patch_ro_slot` consistently.
- User-copy callers use a no-fault-first/retry wrapper through a local macro.
  Its native-copy fallback is defined **before** the macro to avoid recursion.
  Address limits and page-fault state must be restored on all results.
- The local string-copy shim becomes a single-pass, restricted byte loop.
- Optional module-mode kallsyms fallback, ARM64 branch-distance handling and
  mirror diagnostic changes. These are not proof of module-mode operation.
- Updated embedded preinit runner bytes and header. They retain exact upstream
  blob provenance; the binary was not independently rebuilt or executed here.
- Upstream also removes KSU-local warning ratelimiting; this is an upstream
  logging behavior change, not an enabled hook/configuration feature.
